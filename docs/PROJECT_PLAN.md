# Project plan (quick reference)

**Source of truth:** [Notion fieldOS — Project Headquarters](https://app.notion.com/p/417ee3737ed081158adbf79a5c7da5df)

## Current stage: M0 research and domain baseline

- Research how actual FDEs implement customer-specific solutions (company products, job descriptions, public technical material, sanitized workflow examples).
- Compare possible implementation scenarios. **Don't invent the customer systems or their pain points first.**
- Recreate a representative workflow using permitted public/sandbox data.
- Implement it manually; log active work, failures, and correctness.
- Identify which recurring steps tooling could improve; start user outreach in parallel.

## V1 hypothesis (not frozen)

Environment discovery → evidence-backed mapping and blocker identification → actionable engineering handoff → quicker first correct integration.

## Longer term

Web, CLI/IDE, possibly desktop; discovery, solution design, implementation, validation, deployment, post-launch operations. Expand only with observed user value.

## Working agreements

- Every milestone requires evidence of completion.
- Save domain research and product decisions to Notion.
- Do not upload proprietary customer data or credentials.
- Measure active engineering hours and correctness, not AI output volume.
